# Excel Sales Analysis

**Portfolio project | Microsoft Excel | Synthetic 2025 sales data**

## Business question
Which categories, regions and months drive sales revenue?

## Open the project
1. Download `Excel_Sales_Analysis.xlsx` and open it in Microsoft Excel.
2. Start on the **Dashboard** sheet to see KPI cards and charts.
3. Explore the **Sales Data**, **Category Summary**, **Region Summary** and **Monthly Trend** sheets.
4. Read `INSIGHTS.md` for interpretation.

## Skills demonstrated
Spreadsheet formulas (`SUM`, `SUMIF`, `COUNTIF`, `COUNTA`), descriptive KPIs, cross-category summaries, trend analysis and Excel charts. Revenue in the source sheet is calculated as `Quantity × Unit Price × (1 − Discount Rate)`.

## Files
- `Excel_Sales_Analysis.xlsx` — analysis workbook.
- `sales_data.csv` — source data.
- `INSIGHTS.md` — findings.

## Data ethics
Synthetic portfolio demonstration data; not real sales or customer records.
